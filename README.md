# DSA Task - Python Programs

A collection of Python programming practice exercises and foundational DSA concepts.

## 📂 Contents

### 1. Variables (`variable_*.py` / `variables_1.py`)
- Python variable declarations, naming conventions, dynamic typing, and assignments.

### 2. Data Types (`datatype_*.py`)
- Basic built-in data types: integers, floats, strings, booleans, lists, tuples, dictionaries, etc.

### 3. Operators (`operaters_*.py`)
- Arithmetic, comparison, logical, assignment, identity, and membership operators.

### 4. Conditional Statements (`conditions_*.py`)
- `if`, `elif`, `else` constructs and branching logic.

### 5. Loops (`loop_*.py`)
- `for` loops, `while` loops, iteration patterns, and nested loops.

---

## 🚀 How to Run

You can run any script using Python 3:

```bash
python3 filename.py
```
